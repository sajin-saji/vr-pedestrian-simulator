# Unity Assets

Source for the desktop version of the crossing simulator.

| Folder | Content |
|---|---|
| `Scripts/Editor/` | Scene builder (Unity menu: Tools → Pedestrian Simulator) |
| `Scripts/Runtime/Player/` | First-person movement |
| `Scripts/Runtime/Traffic/` | Car spawning and movement |
| `Scripts/Runtime/Simulation/` | Levels, score, collisions, crossing triggers |
| `Scripts/Runtime/Audio/` | Footsteps, ambience, 3D vehicle audio |
| `Audio/Demo/` | Footsteps, city ambience, crowd murmur, engine loop ([details](Audio/Demo/README.md)) |
| `Scenes/` | The generated scene is saved here |

Setup and test checklist: [docs/unity_demo.md](../docs/unity_demo.md)
